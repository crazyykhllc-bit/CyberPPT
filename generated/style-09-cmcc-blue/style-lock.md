# Style 09 锁定说明

来源（同一视觉家族，不是两套风格）：

- `20260615-高校AI Token运营业务内部领导汇报版-V5.1.pdf`（19 页，WPS 演示导出，画布 13.333×7.5 in / 16:9）
- `20260509-数字员工市场调研分析材料-V4.pptx`（10 页，同画布）

已写入仓库默认 9 套（选项 9）。与 **04 象牙白 + 深蓝强调** 最接近但不可互相替代：04 是纸面海军蓝，09 是纯白底 + 高饱和政企蓝铬条。

## 身份

09 是中国移动专属风格。名称仍为「纯白 + 政企蓝（信号黄分章）」。

| 项 | 值 |
|---|---|
| 编号 | 09 |
| 名称 | 纯白 + 政企蓝（信号黄分章） |
| 语气 | 运营商/政企内部领导汇报：结论先行、表格重、动作清单清楚 |
| 适合 | 中国移动内部经营汇报、省市打法、产品套餐、销售话术、风险决策 |
| 不适合 | 高端杂志风、深色驾驶舱、顾问纸面研究（01–03/06）；非移动客户 |

## 色板

| 标题海军蓝 | `#102078` | 卡片标题、结论句、表内行标题 |

| 提示条底 | `#F8F8E0` | 口径/提示条填充 |

强调色只表达优先级：红 = 最高优先，蓝 = 主路径，橙 = 次优先/第三段，黄 = 只做章节导航。

可接受别名（不重锁主值）：`#0070C0`（铬条）、`#0B85CF`（亮轨左）、`#FEE900`（信号黄）、`#10267A`（海军）、`#1F2937`（正文）、`#64748B`（次级）。右上必须放中国移动官方组合标（波浪标 + 中国移动 / China Mobile），资产 `assets/brand-marks/cmcc-logo.png`。不要手绘假标。非移动客户不要选 09，或替换为该客户自己的官方标。

## 表面系统

- 全局连续白纸，不是米卡、不是灰卡。
- 分区靠：实心蓝铬条、6px 左边轨、1px `#D0E0E8` 细边框、浅蓝面板，而不是阴影或大圆角。
- 圆角 2–4px；默认无投影。
- 白色卡片可以大面积使用（与风格 01–08「禁止擅自改白卡片」相反：本风格里白卡片就是主语言）。
- 页眉默认：左实心蓝槽（黄字章节，`#005898` / `#0068C0`）+ 右浅蓝水平渐变斜切条（`#0B85CF` → `#A8E0F8`，上边比下边短形成 `\` 斜边，白字结论）+ 右侧官方组合标（不得被斜切条盖住）。双色实心铬条是同风格变体（经营汇报硬版），不是另一种风格。
- 页脚/SO WHAT：底栏「经营判断 / 对企业的意义」浅槽是经营汇报页型；调研/分析页可用左边轨结论卡替代，不是每页必出。
- 左边轨优先级：红 = 最高优先，蓝 = 主路径，辅橙 `#F79646` = 次优先/第三段/第三卡。样张里左图卡蓝轨、洞察卡 1 红轨、卡 2 蓝轨、价格带卡橙轨，三种轨都合法可见。
- KPI 卡：白底、粗左边轨、大号数字染色、下行说明。数字色随优先级（蓝/红/橙/海军）。
- 提示/口径用浅黄描边条，不用红框。
- 封面/结束页：超大蓝标题 + 中号蓝副标题，允许底部通栏蓝—薄荷丝带（不是仅左下点缀）；右上同样用该官方组合标，不是中性 lockup。
- 页码：右下小蓝块白字，或浅灰数字；不要红印章。

## 网格与页框

- 画布：13.333 × 7.5 in（源文件 960×540 pt）
- 左右安全边约 0.42 in，上下约 0.28–0.35 in
- 顶栏占高约 0.48 in，与内容区间距约 0.16 in
- 内容页常见结构：顶栏 → 蓝色结论副标题（1–2 行）→ 主区（4 卡 / 表 / 时间线）→ 底栏判断
- 表格是主图表语言；少用装饰插画

## 图表与表格

- 宽表 + 圆角横条并列都合法。横条最大项红、其余蓝、浅冰轨道 `#F1F8FA`。不要把横条判成漂移。
- 表头：整行实心 `#0068C0`，白字居中。
- 行：白 / `#F5F8F9` 交替，细线 `#D0E0E8`。
- 首列是行标题，海军蓝加粗。
- 柱状主色中蓝，对比浅蓝；趋势线大红。
- 标签横向直接标在柱/点旁，不用图例替代关键值。
- 流程：圆角方块 + `>`，第一步红底白字，后续蓝底白字。
- 时间线：当前步实心蓝块，后续白底蓝字细边框。

## 图标

- 锁定 `tabler-outline`（源文件是浅底圆 + 细线图标）。
- 图标坐在直径约 28–36px 的浅蓝圆上，线色 `#0068C0`。
- 不混用 filled / duotone。`simple-icons` 只放真实品牌。
- 左上三菱窗：三枚菱形（左上、左下同色蓝 `#1385D0`，右侧绿 `#8DC221`），三角排列、彼此留白缝；是左上装饰，不是商标，不是四宫格。不是图标库的一部分。

## 相对默认其余 8 套的差异

- 比 04 更「体制内」：饱和蓝铬条 + 信号黄分章 + 纯白底，不是象牙纸 + 海军墨。
- 比 01–03 更冷、更少纸质感。
- 白卡片合法，且是默认分区语言。
- 信息密度中高，但以宽表和动作清单为主，少顾问式双轴复杂图。
- 品牌感强：09 是中国移动专属；右上必须用官方组合标 `assets/brand-marks/cmcc-logo.png`，不要手绘假标。三菱窗仍是左上装饰，不是商标。

## 优势 / 风险

- 优势：内部汇报可读、章节导航清楚、表格和打法清单还原稳、省市传达不易跑偏。
- 风险：易做成「默认 PPT 蓝模板」；黄字过面积会廉价；红用多了像告警页；咨询对外材料会显得政企腔。
- 蓝图漂移警报：深色驾驶舱、瑞士网格、杂志海报、 consuting 深红纸面，一律重做。
